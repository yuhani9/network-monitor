# Python Project

Cross-platform Python project template.

## Requirements

- Python 3.11 or later
- Git

## Setup

### Windows (PowerShell)

python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt

### macOS / Linux

python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt

## Run

python src/main.py
